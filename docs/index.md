# Where the documentation is

Documentation here is public unless a page says otherwise.

This repository is a framework people clone and read on GitHub, so its guides live at the
repository root, where a reader lands first. This index registers them rather than copying
them: each link below is the one copy, and a renamed file fails the push until this list is
updated.
